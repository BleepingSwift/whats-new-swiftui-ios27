# WhatsNewSWIFTUIIos27

Sample code demonstrating iOS 27 lets you drag to reorder in any container, add swipe actions outside of List, and cache AsyncImage responses. A tour of the headline SwiftUI changes from WWDC 2026, with code..

> This project accompanies the article: [What's New in SwiftUI for iOS 27](https://bleepingswift.com/blog/whats-new-swiftui-ios27)

## Requirements

- Xcode 27.0+
- iOS 26.0+
- Swift 6.0

## Getting Started

1. Clone this repository
2. Run `xcodegen generate` (requires [XcodeGen](https://github.com/yonaskolb/XcodeGen))
3. Open `WhatsNewSWIFTUIIos27.xcodeproj`
4. Build and run
